# SSHExit

**Твой SSH-сервер — твой выход в сеть.**

Приложение для Android, которое создаёт SOCKS5-прокси или VPN через SSH. Не требует root на телефоне и установки отдельного VPN-демона на сервере.

## Возможности

- Три режима: **SOCKS5**, **VPN**, **SOCKS5 + VPN**.
- Нативный SSH TUN через OpenSSH.
- Подключение через ProxyJump, включая цепочки серверов.
- Поддержка IPv4 и IPv6.
- Общее зашифрованное хранилище приватных SSH-ключей.
- Проверка и сохранение доверенных fingerprint.
- Автоматическая настройка сервера с предварительным просмотром команд и изменением параметров.
- Переподключение после обрыва связи.
- Журнал событий с регулируемой подробностью.
- Светлая и тёмная темы по настройкам Android.

## Быстрый старт

1. Добавьте сервер в разделе **«Хосты»**.
2. При необходимости импортируйте приватный ключ в разделе **«Ключи»**.
3. Выберите режим подключения и промежуточный хост, если нужен ProxyJump.
4. Нажмите на карточку хоста.
5. Проверьте fingerprint сервера и подтвердите доверие.
6. Для VPN предоставьте системное разрешение и подтвердите настройки сервера.

Повторное нажатие на карточку отключает соединение. Остальные действия доступны в меню карточки.

## SOCKS5

Прокси доступен только на устройстве:

```text
Адрес: 127.0.0.1
Порт:  указан в профиле
```

Режим соответствует команде:

```bash
ssh -N -D 1080 user@server
```

С ProxyJump:

```bash
ssh -N -D 1080 -J user@jump user@server
```

Для использования прокси укажите его адрес и порт в приложении с поддержкой SOCKS5.

## VPN через SSH

VPN использует системный `VpnService` Android и нативный канал OpenSSH `tun@openssh.com`.

На сервере необходимы:

- Разрешение `PermitTunnel yes`.
- Доступный `/dev/net/tun`.
- Установленные `iproute2` и `nftables`.
- Разрешённое выполнение команд через SSH.
- Права пользователя на настройку сетевых интерфейсов, маршрутов и firewall.

Приложение не использует `sudo`, `su` и другие способы повышения привилегий. Необходимые права должны быть у SSH-пользователя заранее.

Для полноценного IPv6-туннеля необходим подходящий маршрутизируемый префикс. Подсеть `/64` на внешнем интерфейсе сервера не обязательно подходит для VPN-клиентов без дополнительной настройки маршрутизации или NDP. Приложение не настраивает proxy NDP автоматически.

## Настройка сервера

Перед применением приложение показывает команды настройки и очистки. Можно изменить внешний интерфейс, forwarding, NAT IPv4 и правила accept.

Параметры сохраняются отдельно для каждого хоста после подтверждения. Галочка **«Больше не спрашивать для этого хоста»** отключает повторное подтверждение, включая переподключения. Вернуть запрос можно в редакторе хоста через **«Показывать настройки сервера перед подключением»**. Отмена не сохраняет этот выбор.

В логах отдельно отображаются:

- **ПЛАН** — команды, которые предполагается выполнить.
- **ПРИМЕНЕНО** — операции, успешное выполнение которых подтвердил сервер.
- Результат очистки серверных ресурсов или отсутствие подтверждения.

Приложение использует отдельную таблицу nftables и не выполняет `flush ruleset`. Существующие правила firewall продолжают действовать: accept в таблице приложения не отменяет drop в другой базовой цепочке.

## Авторизация

Ключи из общего хранилища автоматически предлагаются каждому узлу SSH-цепочки. Выбирать отдельный ключ для хоста не требуется.

Если ключи не подошли и сервер разрешает парольную авторизацию, используется сохранённый пароль или запрашивается новый. Запрос указывает конкретный хост и пользователя.

Введённый пароль сохраняется только после успешной парольной авторизации и только если у хоста ещё нет сохранённого пароля. Для зашифрованного приватного ключа отдельно запрашивается парольная фраза.

## Безопасность

- Шифрование паролей и приватных ключей с использованием Android Keystore.
- Проверка и закрепление SSH host keys, включая узлы ProxyJump.
- Предупреждение при изменении доверенного fingerprint.
- Исключение SSH-сокетов из VPN-маршрутизации.
- SOCKS5 доступен только на самом устройстве.
- Пароли, парольные фразы и приватные ключи не записываются в журнал.

Перед подтверждением нового fingerprint сравните его с отпечатком, полученным по доверенному каналу.

Идентификатор приложения: `host.birdiecode.sshexit`. Android устанавливает его отдельно от прежнего приложения `ru.birdiecode.ssh2socks4android`; данные старой установки автоматически не переносятся.

## Текущие ограничения

- Одновременно поддерживается одно SSH VPN-подключение.
- Несколько SOCKS5-подключений могут работать независимо.
- Фиксированные IPv4-адреса туннеля и восстановление глобальных параметров forwarding пока не рассчитаны на несколько одновременных VPN-клиентов одного сервера.
- При потере SSH-соединения очистка серверных ресурсов не гарантируется. Проверяйте журнал и состояние сервера.
- Переключение сетей, восстановление соединений и особенности фоновой работы требуют дополнительного интеграционного тестирования на разных устройствах.
- Серверные lease-записи, reconciliation и общий маршрутизатор нескольких VPN ещё не интегрированы.
